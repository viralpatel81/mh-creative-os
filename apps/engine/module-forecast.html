forecast

Simulate a crowd of fake audience members reacting to the brief, then summarize what they'd do. The most novel and most technical module — it's a graph + memory + multi-agent swarm, not a GPT roleplay.

What it actually does

You hand it: (a) the brief from the brand module, and (b) a folder of supporting documents (product specs, prior posts, market research). It does the following:

  1. Reads the docs and extracts entities — people, claims, products, competitors.
  2. Builds an ontology — what kinds of things matter for this topic, what relationships exist.
  3. Constructs a knowledge graph from the entities and ontology, stored in a graph DB.
  4. Generates audience profiles using oasis (a social network simulator from camel-ai).
  5. Spins up a swarm of agents — each one with their own memory, profile, and view of the graph.
  6. Runs a simulation on a social platform model (Twitter-like, LinkedIn-like, etc).
  7. Reads the simulation logs and writes a structured forecast with scenarios + confidence scores.
Why this is unusual: almost every other "AI predicts engagement" tool just asks an LLM directly. This module simulates an actual network with stateful agents that interact. The output isn't a guess — it's a record of what the simulated crowd did.

The pinned dependencies (don't upgrade these)

The CLAUDE.md explicitly forbids upgrading these. That's a tell — the team has been burned by behavior changes between versions. Pinning at the patch level (not the minor) suggests deep integration.

Why this module matters most for "quality" assessment

This is where most AI repos fail. They claim audience prediction but implement a single LLM call ("predict how X audience would react"). That gives you the LLM's stereotypes, not an audience simulation.

Forecast does the harder thing. Build a graph, populate it with agents, give them memory, let them interact, then read the results. The output is grounded in observed behavior of a simulated network, even if that network is fake.

And it gets calibrated. The metrics module compares forecasted scenarios against realized engagement and updates priors. Over time, the system's predictions should get sharper. (That's the loop.)
